## Task: `1A2B` Game

1. **Rules**: 
   - Right number and Right position give 'A'.
   - Right number and wrong position give 'B'.
   - Input  3 digit can not repeat.
   - Use `GOTO` to be a loop and guess 3A then exit the loop.

## macOS release

The `v1.0.0` GitHub Release includes macOS arm64 executables built with LLVM Flang.
Download and unzip the bundle, then run `run.sh PROGRAM_NAME` from the directory
containing the program's input data. The bundle README lists available programs.
